DUITKU - Android project (WebView wrapper)

1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open > choose this "duitku-android" folder. Let Gradle sync (needs internet the first time).
3. To test: plug in your phone (USB debugging on) or start an emulator, then press Run.
4. To get the APK file: Build > Build Bundle(s) / APK(s) > Build APK(s).
   The file appears in app/build/outputs/apk/debug/app-debug.apk
5. Copy app-debug.apk to your phone and open it. Allow "Install unknown apps" for your file manager if asked.

To change the app later, edit app/src/main/assets/index.html and build again.
